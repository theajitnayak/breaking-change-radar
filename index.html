How this is built

Primary sources or nothing

Every entry carries the vendor page it came from and that page’s publish date. No number appears here that was not printed on a page someone opened.

Doubt is published, not hidden

What cannot be confirmed against a vendor’s own page is still logged and stamped UNVERIFIED. A low-confidence item you can check beats a confident one you cannot.

Quiet weeks stay quiet

A week with no qualifying change produces no entries. Nothing here is padded to look busy, and the commit history shows the gaps.

Open data, correctable

The feed is one JSON file per change in a public repository. If something is wrong, the fix is a pull request rather than an email to me.
